## ما هو

GMD تطبيق أندرويد ينزّل الفيديو والصوت من مئات المواقع ويحوّلهما إلى الصيغة
التي تريد. يعمل كلّه على جهازك: لا خادم وسيط، ولا حساب، ولا إعلان، ولا جمع
بيانات. وهو النسخة المحمولة من [GMD لغنو/لينكس](https://github.com/SalehGNUTUX/GMD)
ويشاركها سلسلة الإصدار نفسها.

يضمّ التطبيق أدواته كاملةً داخله — **yt-dlp** و**ffmpeg** و**aria2c** وبايثون —
فلا يطلب منك تثبيت شيء ولا يحمّل ثنائيّاتٍ عند أوّل تشغيل.

## ✨ المزايا

- ⬇️ **تنزيل فيديو** بجودة تختارها: أفضل متاح، أو 1080p أو 720p أو 480p
- 🎵 **استخراج صوت** بستّ صيغ: MP3 وM4A وOPUS وFLAC وWAV وVORBIS
- 📤 **المشاركة إلى GMD**: شارك الرابط من يوتيوب أو أيّ تطبيق فيفتح GMD جاهزاً به
- 🔗 **فتح الروابط مباشرةً** حين تختار GMD لها
- 📊 **معلومات الوسائط** قبل التنزيل: العنوان والقناة والمدّة والدقّة وعدد المشاهدات
- 🔔 **تنزيل في الخلفيّة** بخدمة مقدّمة وإشعار تقدُّم — لا يتوقّف حين تغادر التطبيق
- 📁 **حفظ في معرض الوسائط** عبر MediaStore، فتجد الملفّ في تطبيق المعرض مباشرةً
- 🔄 **تحديث ذاتيّ**: يتحقّق من الإصدارات وينزّلها ويسلّمها لمثبّت النظام
- 🧰 **تحديث yt-dlp** من داخل التطبيق — وهو الجزء الذي يحتاج تحديثاً متكرّراً
- 🌍 **عربيّ وإنجليزيّ** بواجهة تدعم الاتّجاهين
- 🎨 واجهة **Material 3** بـ Jetpack Compose

## 📥 التنزيل والتثبيت

نزّل الحزمة من [صفحة الإصدارات](https://github.com/SalehGNUTUX/GMD-PHONE/releases).

| الحزمة | لمن |
|---|---|
| `arm64-v8a` | أغلب هواتف اليوم |
| `armeabi-v7a` | هواتف قديمة 32-بت |
| `x86_64` | المحاكيات وبعض الأجهزة اللوحيّة |
| `universal` | إن لم تعرف معماريّة جهازك — أكبر حجماً |

بعد التنزيل سيطلب أندرويد إذن **تثبيت التطبيقات المجهولة**؛ هذا لأنّ GMD لا
يُوزَّع عبر متجر، وليس لأنّ فيه شيئاً. تحقّق من بصمة الحزمة إن شئت بمقارنتها
بملفّ `SHA256SUMS.txt` المرفق بالإصدار.

## 🚀 البناء من المصدر

```bash
git clone https://github.com/SalehGNUTUX/GMD-PHONE.git
cd GMD-PHONE

# حزمة للتجربة
./gradlew assembleDebug

# حزمة إصدار موقَّعة — تحتاج keystore.properties (انظر أدناه)
./gradlew assembleRelease
```

المخرجات في `app/build/outputs/apk/`.

### التوقيع

حزم الإصدار يجب أن تُوقَّع وإلّا رفض أندرويد تثبيتها. أنشئ `keystore.properties`
في جذر المشروع — وهو مستثنى من git ولا يُودَع أبداً:

```properties
storeFile=/مسار/إلى/مفتاحك.jks
storePassword=…
keyAlias=…
keyPassword=…
```

وفي CI تُقرأ القيم نفسها من متغيّرات البيئة `GMD_KEYSTORE_FILE` و
`GMD_KEYSTORE_PASSWORD` و`GMD_KEY_ALIAS` و`GMD_KEY_PASSWORD`.

> مفتاح التوقيع هو هويّة التطبيق عند أندرويد. احتفظ بنسخة احتياطيّة منه ومن
> كلمة سرّه: فقدانه يعني استحالة إصدار تحديثٍ لمن ثبّت التطبيق، وتسريبه يعني
> أنّ غيرك يستطيع نشر تحديثٍ ينتحل صفة GMD.

## 🏛️ البنية

```
app/src/main/java/com/gnutux/gmd/
├── MainActivity.kt          # نقطة الدخول، واستقبال الروابط المشاركة
├── GmdApp.kt                # تهيئة التطبيق وأدواته
├── download/
│   ├── Downloader.kt        # غلاف yt-dlp — كلّ قيمة تدخل خانة مستقلّة
│   ├── DownloadService.kt   # خدمة مقدّمة بإشعار تقدُّم
│   └── MediaStoreSaver.kt   # النقل إلى معرض الوسائط
├── ui/
│   ├── GmdApp.kt            # الهيكل والتنقّل
│   ├── Screens.kt           # شاشات التنزيل والمعلومات والإعدادات
│   ├── GmdViewModel.kt      # الحالة
│   └── Theme.kt             # سِمة Material 3
├── update/Updater.kt        # التحقّق من التحديثات وتنزيلها
└── data/Settings.kt         # الإعدادات بـ DataStore
```

**متطلّبات البناء:** JDK 17، وAndroid SDK بمنصّة 36. أدنى إصدار أندرويد مدعوم
7.0 (‏API 24)، وهو أدنى ما تدعمه مكتبة yt-dlp لأندرويد.
